# LegacyAI

AI decision making system for business, building for BuildFastAI.

## Project Structure

```
LegacyAI/
├── docs/      # Documentation and design notes
├── src/       # Application source code
├── tests/     # Automated tests
├── .gitignore # Common local/build artifacts to ignore
└── README.md
```

## Getting Started

1. Add your implementation under `src/`.
2. Add tests under `tests/`.
3. Keep architecture and usage documentation in `docs/`.
